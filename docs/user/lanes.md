# Lanes

Lanes shows up to eight threads side by side, so you can watch several agents
work and reply to any of them without switching threads. Each lane is a live
chat with its own composer.

## Open lanes

Open **Lanes** from the sidebar or the command palette, or press `mod+alt+l` on
web and desktop when the terminal is not focused. Customize `lanes.open` in
**Settings → Keybindings**.

To add threads:

- Right-click a thread in the sidebar and choose **Add to lanes**. Select several
  threads first to add them all at once.
- Choose **Add to lanes** from the thread's header menu.
- On the Lanes page, choose **Add lane** to search for a thread, or
  **Add active threads** to add every thread that is working or needs your
  attention.

## Work with lanes

Double-click a lane's header to focus it on its own, and again to return to all
lanes. Drag a header to reorder lanes. Closing a lane only removes it from Lanes;
the thread is not archived or deleted.

A lane has no diff panel or terminal. Opening a tool's diff from a lane opens the
full thread, and a suggested shell command is copied for you to run in the
thread's terminal.

Lanes are saved in this browser or desktop app, so each device keeps its own set.
In-app notifications are skipped for threads you can already see in a lane.
